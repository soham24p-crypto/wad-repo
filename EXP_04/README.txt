EXP_04 - Authentication (bcrypt + Express sessions + MySQL)
1. Start MySQL in XAMPP
2. Run:   npm install   then   npm start
3. Open http://localhost:3000  -> Create Account -> Login -> Dashboard -> Logout
4. Check the hashed password: phpMyAdmin -> auth_db -> users
   (if MySQL has a root password: set DB_PASS as in EXP_03)
