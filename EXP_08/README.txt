EXP_08 - Mobile app fetching data from a REST API (works on Android + iOS browsers)
Run:   npm install   then   npm start
PC:    http://localhost:3000
Phone: connect to the SAME Wi-Fi, open http://YOUR-PC-IP:3000
       (find IP: Windows -> ipconfig, Mac -> ipconfig getifaddr en0)
Test API in Postman: GET and POST http://localhost:3000/api/complaints
