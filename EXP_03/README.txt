EXP_03 - Registration form with CRUD (Express + MySQL)
1. Open XAMPP and click Start next to MySQL
2. Run:   npm install   then   npm start
   (database + table are created automatically)
   If your MySQL root has a password:  Mac/Linux: DB_PASS=yourpass npm start
                                        Windows:   set DB_PASS=yourpass && npm start
3. Open http://localhost:3000
