# Experiments (EXP_01 - EXP_08)
Each folder has its own README.txt with run steps.

Needed on the PC: Node.js (nodejs.org), Python 3 (EXP_06, EXP_07), XAMPP with MySQL (EXP_03, EXP_04, EXP_05).

| Folder | Topic | Needs |
|---|---|---|
| EXP_01 | Web server with Node http | Node |
| EXP_02 | Express static site | Node |
| EXP_03 | Registration form CRUD | Node + MySQL |
| EXP_04 | Login + bcrypt + sessions | Node + MySQL |
| EXP_05 | SQLi / XSS / CSRF fixes | Node + MySQL |
| EXP_06 | CI/CD for ML (Flask, Docker, Jenkins) | Python (Docker/Jenkins optional) |
| EXP_07 | Model drift monitoring | Python |
| EXP_08 | REST API + mobile-friendly app | Node |

Quick start for Node experiments: `cd EXP_02` then `npm install` then `npm start`, open http://localhost:3000
(All Node experiments use port 3000, so press Ctrl + C to stop one before starting another.)
